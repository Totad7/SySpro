# SySpro v1.8 - PC DIAGNOSTIC TOOL 
Comprehensive System Testing
SySpro: Ваш помощник в диагностике ПК

## Функции

**Основные тесты:**
- System Information - информация о системе
- Memory Test - тест оперативной памяти
- CPU Stress Test - нагрузка процессора
- Disk Speed Test - скорость SSD/HDD
- GPU Benchmark Test - тест видеокарты

**Дополнительно:**
- Test Data Table - таблица результатов
- Run ALL Tests - все тесты подряд
- 3D Test - тестирование графики
- OpenHardwareMonitor - мониторинг температуры
- Feedback & Links - обратная связь

## Запуск

**Требования:** Windows 7/8/10/11

**Обязательно:**
- Запускайте `SySpro.exe` **от имени администратора**

**Если OpenHardwareMonitor не работает:**
1. Запустите SySpro от администратора
2. Убедитесь, что папка OpenHardwareMonitor в той же папке с SySpro
3. При отсутствии данных обновите драйверы

## Управление

Выбор опций клавишами:
- **[1-5]** - отдельные тесты
- **[6]** - таблица данных  
- **[7]** - все тесты
- **[8]** - 3D тест
- **[9]** - выход
- **[i]** - вкл/выкл OpenHardwareMonitor
- **[?]** - обратная связь

## ⚠️ Важно

- Требуются права администратора
- Нет данных - обновите драйверы

*Убедитесь, что антивирус не блокирует программу*
